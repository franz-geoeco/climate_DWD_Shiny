about=Ports the "German Climate Dashboard" R/Shiny app to a QGIS plugin. Loads all ~6000 DWD weather stations as a real QGIS point layer (colour-coded by data availability), lets you click a station on the map canvas to inspect it, plots daily temperature/precipitation, hourly wind, 30-year climate diagrams, temperature trend & anomaly, and annual climate indices via embedded matplotlib panels, downloads Germany-wide 1km x 1km interpolated climate grids straight into the map as styled raster layers, and charts phenological phase data (sowing, flowering, ripening, leaf colouring, ...) for field crops, fruit, vine and wild plants from DWD's separate phenology station network. All data comes live from the DWD Open Data portal (opendata.dwd.de). Requires the requests, pandas, numpy and matplotlib Python packages; these are already bundled with recent QGIS standalone installers, but if QGIS reports an import error, install them into QGIS's own Python via the OSGeo4W shell: python -m pip install requests pandas numpy matplotlib.
